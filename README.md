# Aditya Jagdhane — Official Website

This is the **official website of Aditya Jagdhane**, an Indian musician, singer-songwriter, and composer.  
It serves as a central hub for his music, projects, collaborations, and updates.

---

## Live Website
**[https://www.adityajagdhane.in](https://www.adityajagdhane.in)**

---

## About the Project
This portfolio website is designed and developed to represent **Aditya Jagdhane’s professional profile** — including his discography, biography, and creative works.

Built with modern technologies for speed, aesthetics, and accessibility.

---

## Tech Stack
- **Framework:** [Vite](https://vitejs.dev/)  
- **Languages:** HTML5, CSS3, TypeScript  
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)  
- **UI/UX Design:** [Dualite](https://dualite.app/) (no-code export)  
- **Hosting:** [Netlify](https://www.netlify.com/)  
- **Domain:** [adityajagdhane.in](https://www.adityajagdhane.in)
